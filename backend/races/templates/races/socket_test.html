Race WebSocket test

This developer page tests live messages. It is not the typing game.

  1. Sign into admin in this browser.
  2. Create or join a race through the race API. Your account must be a participant.
  3. Open this page in two tabs, enter the same race ID in both, and connect.
  4. Send a message in one tab. Both tabs should receive it.

For a regular player's API token, use a separate private browser window without an admin login and paste the token below. A signed-in browser uses its admin session.
